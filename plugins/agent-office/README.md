# Agent Office

A Claude Code mod that shows Claude and its helper agents as people working in a small animated office. Each helper walks in through the door, sits at its own desk, shows an icon for what it's doing, raises a hand when it needs your approval, and walks out with a green check when it's done. Open it with `/office`.

Install from the repository's marketplace:

```
/plugin install agent-office --marketplace Naumansaf/agent-office
```

See the README at the root of the repository for the full guide.
