# Changelog

## 0.2.0

- Helpers now walk in, sit at their own desk and stay there until they finish, instead of walking to a different spot for every tool.
- An icon above each helper shows what it's doing (editing, running a command, researching, reading files, using an app, planning, thinking), and the light from its screen changes color with it.
- Helpers raise a hand at their desk when they need approval.
- The server rack and whiteboard react to what people are doing.

## 0.1.0

- First release: an animated isometric office with one character per helper agent, name tags from each agent's task, and a live list of agents.
